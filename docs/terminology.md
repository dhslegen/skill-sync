# 用户文案术语对照表

全部用户可见文案走 i18n 资源(架构铁律 6),**禁止出现左列 git 术语**,一律使用右列产品用语。
错误提示必须附"下一步动作"(如:网络不通 → 检查是否连接公司内网/VPN)。

| 禁用(git 术语) | 使用(产品用语) |
|---|---|
| commit / 提交(git 义) | 保存 |
| push / 推送 | 分享 |
| pull / fetch / clone / 拉取 | 获取 |
| repository / repo / 仓库 | 技能库 |
| branch / 分支 | (不出现) |
| PR / merge request | 提交审核 |
| merge / 合并(git 义) | (不出现) |
| token(面向非研发) | 登录凭证 |
| sha / commit id | 版本标识(仅以等宽短码展示,不解释) |

按钮文案短促(UI 规范 §2.7):「安装」不是「立即获取 →」;「已启用」不是「启用成功!」。
